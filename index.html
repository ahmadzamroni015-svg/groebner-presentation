🤔 Mengapa Metode Konjugat Biasa Sulit?

📌 Untuk √3 saja

\[ \frac{1}{x+\sqrt{3}} = \frac{x-\sqrt{3}}{x^2-3} \]

✅ Cukup 1 kali perkalian konjugat

Mudah!

📌 Untuk ∛5 saja

\[ \frac{1}{x+\sqrt[3]{5}} = \frac{x^2 - x\sqrt[3]{5} + \sqrt[3]{25}}{x^3+5} \]

⚠️ Perlu 3 faktor konjugat

Mulai rumit

📌 Untuk √3 + ∛25

\[ \frac{1}{x+\sqrt{3}+\sqrt[3]{25}} \]

❌ Perlu 6+ kali perkalian konjugat

❌ Hasil pembilang puluhan suku

Sangat rumit!

✨ Kesimpulan: Metode konjugat biasa tidak praktis untuk kombinasi akar berbeda. Dibutuhkan pendekatan yang lebih sistematis, yaitu Gröbner Basis.

📚 Teori 1: Gröbner Basis

Landasan Teori
Definisi: Himpunan \(G \subseteq I\) disebut Gröbner basis terhadap monomial order \(>\) jika:
\[ \langle \operatorname{LT}(g) : g \in G \rangle = \langle \operatorname{LT}(f) : f \in I \rangle \]

📖 Teorema Buchberger

Setiap ideal \(I \subseteq k[x_1,\ldots,x_n]\) memiliki Gröbner basis yang dapat dihitung dengan algoritma Buchberger.

📖 Teorema Eliminasi

Jika \(G\) adalah Gröbner basis terhadap lex order dengan \(x_1 > x_2 > \ldots > x_n\), maka \(G \cap k[x_{\ell+1},\ldots,x_n]\) adalah basis dari ideal eliminasi.

📚 Teori 2: Resultant

Alat Eliminasi
Teorema: \(\operatorname{Res}_x(f,g) = 0 \iff f\) dan \(g\) memiliki akar bersama.
\[ \text{minpoly}_s(x) = \operatorname{Res}_{y_2}\left( y_2^3-5,\; \operatorname{Res}_{y_1}(x+y_1+y_2^2,\; y_1^2-3) \right) \]
✨ Aplikasi: Eliminasi variabel bertahap tanpa mencari GCD, menghasilkan polinomial minimal.

🔍 Bagaimana Resultant Bekerja?

📐 Definisi

Resultant adalah determinan matriks Sylvester yang bernilai nol jika dua polinomial memiliki akar bersama.

\[ \text{Res}_x(f,g) = a_m^n \prod_{i=1}^m \prod_{j=1}^n (\alpha_i - \beta_j) \]

⚡ Aplikasi dalam Eliminasi

Untuk eliminasi \(y_1\):

\[ \text{Res}_{y_1}(x+y_1+y_2^2,\; y_1^2-3) \]

→ Menghilangkan \(y_1\), menghasilkan polinom dalam \(y_2\) dan \(x\)

📊 Ilustrasi Eliminasi Bertahap

Langkah 1

Eliminasi \(y_1\)

\( \text{Res}_{y_1} \)

▼

Polinom dalam \(y_2, x\)

+
Langkah 2

Eliminasi \(y_2\)

\( \text{Res}_{y_2} \)

▼

Polinom dalam \(x\) saja!

🌿 Mengapa Basis Medan Penting?

📐 Derajat Perluasan Medan

\[ [\mathbb{Q}(\sqrt{3},\sqrt[3]{5}):\mathbb{Q}] = 2 \times 3 = 6 \]

Artinya: Setiap elemen medan dapat dinyatakan sebagai kombinasi linear dari 6 basis dengan koefisien di \(\mathbb{Q}\).

🔢 Basis Medan

\[ \mathcal{B} = \{1, \sqrt{3}, \sqrt[3]{5}, \sqrt[3]{25}, \sqrt{3}\sqrt[3]{5}, \sqrt{3}\sqrt[3]{25}\} \]

Ini seperti vektor basis di ruang vektor 6 dimensi!

📝 Koefisien dalam \(\mathbb{Q}(x)\)

Untuk soal kita, koefisiennya berupa polinomial dalam x:

\[ A(x) = -x^5 + 6x^3 - 9x \] \[ B(x) = -x^4 + 3x^2 - 3 \] \[ C(x) = -x^3 + 3x \] \[ D(x) = x^2 - 1 \] \[ E(x) = -x \] \[ F(x) = 1 \]
🎯 Intinya: Hasil rasionalisasi selalu dapat ditulis dalam bentuk 6 suku ini, tidak lebih!

📜 Kode Singular Lengkap

// ============================================
// Rasionalisasi 1/(x + sqrt(3) + cuberoot(25))
// dengan Gröbner basis dan resultant
// ============================================

// Load library
LIB "general.lib";
LIB "elim.lib";

// STEP 1: Definisikan ring polinomial
// (0,x) = field fungsi rasional dalam x
// (y1,y2) = variabel untuk akar
// lp = lexicographic order (y1 > y2)
ring R = (0,x), (y1, y2), lp;
option(redSB);

// STEP 2: Bentuk ideal I
ideal I = y1^2 - 3,          // y1 = sqrt(3)
          y2^3 - 5,          // y2 = cuberoot(5)
          x + y1 + y2^2;     // penyebut s

// STEP 3: Hitung Resultant
poly s = x + y1 + y2^2;
poly res_y1 = resultant(s, y1^2-3, y1);
poly minpoly_s = resultant(res_y1, y2^3-5, y2);

// STEP 4: Ekstrak koefisien
poly a0 = coefficient(minpoly_s, s, 0);
poly a1 = coefficient(minpoly_s, s, 1);
poly a2 = coefficient(minpoly_s, s, 2);
poly a3 = coefficient(minpoly_s, s, 3);
poly a4 = coefficient(minpoly_s, s, 4);
poly a5 = coefficient(minpoly_s, s, 5);

// STEP 5: Rumus 1/s
// 1/s = -(a1 + a2*s + a3*s^2 + a4*s^3 + a5*s^4 + s^5)/a0

// STEP 6: Substitusi ke basis medan
ring R2 = (0,x), (y1, y2), lp;
ideal rel = y1^2-3, y2^3-5;
ideal std_rel = std(rel);

poly s2 = x + y1 + y2^2;
poly a0_expr = x^6 - 9*x^4 + 9*x^2 - 27;
poly a1_expr = -6*x^5 + 36*x^3 - 54*x;
poly a2_expr = 15*x^4 - 15*x^2 + 27;
poly a3_expr = -20*x^3 + 30*x;
poly a4_expr = 5*x^2 - 9;
poly a5_expr = -6*x;

poly numerator_s = -(a1_expr + a2_expr*s2 + a3_expr*s2^2 + a4_expr*s2^3 + a5_expr*s2^4 + s2^5);
poly num_reduced = reduce(numerator_s, std_rel);

// Hasil akhir
"Hasil Rasionalisasi:";
"1/(x + sqrt(3) + cuberoot(25)) = ";
num_reduced;
"-----------------------------------------------------------------";
a0_expr;
